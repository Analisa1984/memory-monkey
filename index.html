Welcome to Memory Monkey

About Us

Memory Monkey is designed for anyone searching to have some fun during their leisure time. Memory Monkey is a memory game and is relatively easy to play and games such as these may improve memory.

How to Play

Welcome to Memory Monkey! To play this cheeky mind game, first a single image will be shown for 3 few seconds. the second round will then show 3 images and each subsequent round will show an additional image. Your task will be to remember the images in the order it is shown to you. After the images disappear, you will be prompted to select the images in the correct order. The game will keep track of your score (shown to you in the red oval image written as score) and rounds. Try to get the highest score possible!

If you enter the items in the correct order as shown, you get 10 points and your score increases. If you enter the sequence incorrectly, you will lose 2 points and the game will prompt you to enter the correct items again. If you enter the sequence of items correctly, you will advance to the next round.

At the end of the game you will be given the option to proceed to a new game. If you get stuck in the game you can choose to start a new game.

Enjoy and have fun!
